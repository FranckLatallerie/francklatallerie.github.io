Data

SS3DPacific

Surface-wave tomography of the Pacific upper-mantle, with resolution and uncertainty, computed using 3D finite-frequency and Backus-Gilbert theory. The dataset includes the model, the uncertainty, the matrices to compute resolution kernels, as well as the input data (Rayleigh wave phase-delays), and some routines to compute resolution kernels and produce some plots. More information in the repository. This dataset is related with the manuscript Latallerie et al., 2026, GRL (10.1029/2025GL119309). BGS repository here: https://doi.org/10.5285/17fd6862-c3e8-4fb4-a33d-64c1cedc2d3f
