SOLAbase

The SOLAbase software is a modular Python package to solve linear tomography problems in the form d=Gm+n using the Backus-Gilbert-based SOLA method, accounting for resolution and uncertainty. The software can be installed with pip or directly from source. More information at the links below:
  • PyPI
  • ReadTheDocs
  • Repository
